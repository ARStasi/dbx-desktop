## Question

What desktop organization makes it easier to find and reopen notebooks, SQL queries, data, and volumes, and how should drag-and-drop file uploads fit into that organization?

Use a rough prototype for the user to react to. Compare only concrete alternatives relevant to their workflow, such as a workspace tree and recent items versus project-specific shortcuts. Show remote location, chosen compute, run status, and upload destination. Keep volume interactions inside the app. Resolve overwrite, progress, and failed-transfer presentation only to the extent visible in this discussion; do not build a sync engine.
